# Divar - Marketplace App

A React marketplace app where users can post product listings and browse what others have listed. Built as a practice project modelled on a classifieds marketplace.

## Features

- Post a product listing
- Browse and view listings
- Client-side routing between list and detail views
- Toast notifications for user feedback

## Built with

- React 18
- Vite 5
- React Router 6
- TanStack Query 4 and Axios for data fetching
- react-hot-toast for notifications

## Running locally

This app expects a backend API. Create a .env file and set VITE_BASE_URL to point at it.

```bash
npm install
npm run dev
```
